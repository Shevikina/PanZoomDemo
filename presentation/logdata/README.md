# Сырые данные замеров

Что где лежит.

| Каталог | Что внутри |
|---------|-----------|
| `logcat/` | 25 логов серии, по одному на прогон |
| `gfxinfo/` | дампы `dumpsys gfxinfo`, имена совпадают с логами |
| `csv/` | разбор логов: метрики, jank, пул, тайлы, summary |
| `perfetto/` | два трейса, GL вкл и выкл, с разбором и сравнением |
| `layout_inspector/` | два видео счётчика рекомпозиций, отдельно с тумблером и без |

Layout Inspector снимается только на debug-сборке, поэтому числа оттуда в таблицы не идут.
Это материал для живого демо. Видео разбиты на два, по состоянию тумблера:
`layout_inspector_gl-on.mov` и `layout_inspector_gl-off.mov`.

Имя прогона устроено так: `<кейс>_<сценарий>_<устройство>_<дата>_<время>`. Сценарий это
жест из протокола, кейс это конфигурация тумблеров. Разбор и медианы лежат в
[logs_measurements.md](../logs_measurements.md) и [gfx_measurements.md](../gfx_measurements.md).

Видео прогонов сюда не кладутся, они весят под гигабайт на серию.
